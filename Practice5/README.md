# Practice 5 – Python Regular Expressions

This project demonstrates the use of Python RegEx.

## Files

regex_exercises.py
Examples of Python regex patterns.

receipt_parser.py
Parses receipt data from raw.txt.

Original receipt text.

## Features

- Extract product names
- Extract prices
- Extract total amount
- Extract date and time
- Detect payment method
